# PlexDL

App macOS tải video YouTube, Vimeo, Instagram ra MP4 (H.264 + AAC), quét trang Pinterest/Vimeo để gom link video.

**Tải bản mới nhất:** [Releases](https://github.com/mrkunvo/plexdl-releases/releases/latest) → file `PlexDL-<bản>.dmg`.

- Cần máy Mac chip Apple (M1 trở lên), macOS 14 trở lên.
- Mở DMG, kéo PlexDL vào Applications.
- Lần đầu mở: Cài đặt hệ thống → Quyền riêng tư & Bảo mật → **Vẫn mở**.
- Từ bản 3.2.1, app tự kiểm bản mới mỗi lần mở (hoặc menu PlexDL → Kiểm tra cập nhật…).
